# Nebulosa Site

## English

Nebulosa Site is a website project built with Astro, focused on delivering a clean, responsive, and engaging web experience.

## Features

- Responsive layout for desktop, tablet, and mobile devices
- Clean and accessible user interface
- Organized structure for easy maintenance and expansion
- Modern visual design inspired by the universe and nebulas
- Built with Astro for fast performance and simple content organization

## Project Structure

```bash
.
├── public/
│   └── assets/
├── src/
│   ├── components/
│   ├── layouts/
│   ├── pages/
│   ├── styles/
│   └── content/
├── astro.config.mjs
├── package.json
├── README.md
└── tsconfig.json
```

## Getting Started

1. Clone or download this repository.
2. Open the project folder in your preferred code editor.
3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the URL shown in the terminal.
